The Big Picture

AI 가속기 수요가 HBM·CoWoS 패키징을 병목으로 만들면서, 밸류체인 전 업종의 컨콜이 사실상 같은 대본을 읽고 있다 — "AI가 유일한 성장 동력, 나머지 전방(PC·모바일·오토·산업)은 부진." 2025년의 병목은 기술이 아니라 물리적 캐파(floor-space)로 옮겨갔고, 이는 곧 다년 증설(capex) 사이클과 테스트·검사 인텐시티 상승을 의미한다. HBM4 전환이 2026~27년 차수 상향의 방아쇠다.

업종별 발언 정리

각 업종은 컨콜에서 무엇을 말했나

업종별 한 줄 메시지 + 투자자가 볼 시그널, 그리고 개별 기업의 대표 발언(패키징 관련). 수치는 회사 공시·컨콜 기준이며 인용 전 원문 재확인 권장.

여기서 뽑을 수 있는 것

핵심 포인트 8

여러 업종의 발언이 서로 교차 검증하는 구조적 포인트만 추렸다. 근거는 실제 회사·수치.

1

전 밸류체인이 같은 대본 — "AI만 좋고 나머지는 부진"

14개사 컨콜의 공통 코러스. 패키징 수혜는 AI 단일 축 의존이라는 확신이자, 곧 집중 리스크이기도 하다.

근거 · Advantest "자동차·산업 부진" / DISCO "PC·폰·오토·전력 약세" / Technoprobe "Consumer 2027 전 회복 없음" / Teradyne "사이클 둔화를 AI가 상쇄"
2

병목이 '기술'에서 '공간'으로 이동 → 증설 사이클

수요 부족이 아니라 캐파·플로어스페이스 부족이 성장을 제약. 이는 장비·검사사에 다년 수주 가시성으로 직결된다.

근거 · Amkor "캐파가 병목" / KYEC "플로어스페이스가 제약" / KLA "제약은 툴 아닌 고객 공간" / Onto "고객이 툴 20% 추가 필요"
3

"테스트 인텐시티" 상승 = 테스트 3업종 동시 레버리지

칩당 테스트 시간·핀수·병렬도 상승 → 같은 물량에도 매출이 는다. ATE·프로브카드·테스트하우스가 볼륨보다 강하게 성장.

근거 · Advantest "HBM4 288GB 테스트 시간↑" / Teradyne 컴퓨트가 SoC >50% / Technoprobe "복잡도→테스트 요구" / KYEC AI 테스트 급증
4

HBM4 전환이 2026–27 차수 상향의 방아쇠

층수·범프밀도·대역폭 동반 상승 → 프로브·계측·검사·본딩 스텝당 콘텐츠 증가. 여러 사가 대형 수주·목표 상향으로 확인.

근거 · Camtek HBM $260M+ / Onto HBM VPA $240M+(3D $60M) / FormFactor Smart Matrix 유일 검증 / KLA "금속층↑→검사↑"
5

HBM 다음 프론티어 = 2.5D 로직 + 패널레벨(FOPLP)

성장이 HBM 메모리에서 CoWoS/2.5D 로직으로, 그다음 패널레벨로 확산. 장비사엔 신규 TAM, 현재는 초기 램프.

근거 · Onto "2.5D 주문 QoQ 2배" · JetStep 패널 8대(~$200M 시장) / SÜSS 310×310 스캐너 / KLA "점유 확대는 CoWoS 로직 중심"
6

CPO·실리콘 포토닉스 = 공짜 옵션, 다수가 동시 진입

아직 매출은 미미하나 4개사 이상이 동시 베팅. 다음 사이클의 옵션성으로 보유할 만한 테마.

근거 · FormFactor Triton/Keystone($10–20M) / Teradyne Photon 100·MLTP JV / Technoprobe·MPI CPO 양면 / Onto CPO "5년 30% CAGR"
7

수직통합·M&A로 업종 경계가 무너진다

프로브카드↔테스트, 계측↔검사, OSAT↔파운드리 경계가 흐려지며 파트너십·인수로 콘텐츠를 확장. 경쟁 지형이 재편 중.

근거 · Technoprobe+Teradyne(DIS 인수·지분10%) / Amkor+TSMC 10년 / Onto(Rigaku·Semilab·Visual Layer) / FormFactor(Keystone·FICT)
8

실적 서프라이즈 ≠ 주가 — 기대가 이미 높다

사상 최대 실적에도 가이드·마진 궤적에 주가가 흔들리는 사례 빈번. 관건은 '얼마나 좋았나'가 아니라 '눈높이를 넘었나'.

근거 · Advantest 보수적 마진 가이드에 하락 / Teradyne 호실적에도 2Q 둔화 가이드로 −19% / Camtek 실적 상회에도 OM·opex로 하락

엇갈리는 신호 · 유의점

⚠ Watch — 반대편에서 봐야 할 것

  • 수주 ≠ 매출 (시차): SÜSS는 수주 사상 최대(BB 1.73)인데 매출은 저점, 2026 '전환의 해' — 신제품 P&L 기여는 2027부터. HBM '소화(digestion)'로 본더 매출이 줄던 국면도 있었다.
  • 하이브리드 본딩은 아직 초기: wafer-to-wafer는 SÜSS 스스로 "선두 아님", Camtek도 본격 기여 2027 — 상용화 시점·승자 불확실.
  • 분기 변동성: DISCO·TEL은 집중출하의 반작용으로 메모리 출하가 분기별 출렁 — 한 분기 숫자로 추세를 단정 말 것.
  • 데이터 신뢰도: KYEC·MPI 등 대만 중소형주는 영문 어닝콜 전문이 없어 중국어 법설·2차 요약 기반 — 세부 재무 검증에 제약.
